## Context

These posters represent bioinformatics analyses I led or contributed to as part of the computational biology team at Kronos Bio. Work included network-based multi-omics integration (RNA-seq + ChIP-seq), ML-driven mechanism of action studies, custom RNA-seq pipelines, and high-throughput drug combination screening (PRISM, ~950 cell lines).
